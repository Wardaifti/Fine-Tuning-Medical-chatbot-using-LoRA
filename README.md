# Fine-Tuning-Medical-chatbot-using-LoRA

# Project Overview:
This project focuses on fine-tuning a pre-trained language model specifically for medical question answering tasks using LoRA (Low-Rank Adaptation) — a parameter-efficient fine-tuning technique. The goal was to build a lightweight yet capable medical chatbot that can handle patient queries in a conversational style.

# Key Highlights:

✅ Fine-tuned a causal language model (e.g., Mistral or TinyLLaMA) using LoRA for medical domain data.

✅ Integrated the model into a Flask web app with an intuitive frontend using HTML, CSS, and JavaScript.

✅ Built support for real-time chatbot interactions with user input/output tracking.

✅ Experimented with lightweight models to ensure performance on systems with limited RAM (2–4 GB).

✅ Deployed and tested the app locally, and optimized for both performance and accuracy.

# Technologies Used:

🧠 Transformers (Hugging Face)

⚙️ LoRA (PEFT library)

🧪 Datasets from medical QA sources

🧰 Flask (backend), HTML/CSS/JS (frontend)

🧮 PyTorch

🧪 Quantization & Low-memory tricks (4-bit/8-bit loading)
